# IARC 年齡分級問卷建議答案

Partner Center →「年齡分級」會出現 IARC 問卷。qScreenRec 屬於工具類，建議如下作答，結果通常為 **3+ / 普遍級**。

| 問題（意譯） | 建議答案 | 說明 |
|---|---|---|
| 應用程式類別 | 公用程式、生產力、通訊或其他（Utility / Productivity） | 非遊戲、非社群 |
| 是否含暴力、血腥、色情、粗話、毒品、賭博內容 | 否 | |
| 使用者之間能否互動或交換內容 | 否 | 無線上功能 |
| 是否分享使用者的位置 | 否 | |
| 是否可購買數位商品 | 否（v1）| 日後若加入付費功能需回來更新 |
| 是否可無限制存取網際網路（內建瀏覽器） | 否 | |
| 是否蒐集個人資訊 | 否 | 見隱私權政策 |

> 注意：螢幕錄影工具可能錄到使用者畫面上的任何內容，但這不屬於 App 本身提供的內容，問卷不需因此勾選。
