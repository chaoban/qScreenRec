# 屬性（Properties）

| 欄位 | 建議值 |
|---|---|
| 類別 | 相片與影片（Photo & video）；次類別可選「生產力」 |
| 隱私權原則 URL | 【待填：privacy_policy 公開網址】 |
| 網站 | 【待填：可用 https://github.com/chaoban/qScreenRec 】 |
| 支援連絡資訊 | aisais.dev@gmail.com |
| 產品宣告 | 勾選「此產品可讓使用者存取／錄製其他內容」不需要；不勾選「需要 Microsoft 帳戶」 |
| 系統需求 – 最低 | Windows 10 版本 1903（18362）以上、x64、DirectX 11 顯示卡、4 GB 記憶體 |
| 系統需求 – 建議 | Windows 11、支援硬體編碼的 NVIDIA／Intel／AMD 顯示卡、8 GB 記憶體 |
| 硬體 – 輸入 | 鍵盤、滑鼠 |
| 顯示模式 | 不適用（桌面應用程式） |
| 隱私權 – 個人資訊 | 不存取、不蒐集、不傳輸個人資訊 |
