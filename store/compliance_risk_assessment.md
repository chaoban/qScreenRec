# 上架合規與風險評估

評估日期：2026-11-27　版本：qScreenRec 1.0.0　結論：**可上架，整體風險低**。下表「狀態」為 OK 的項目已在程式或文件中處理；標示「上架前確認」的需要你在 Partner Center 操作時留意。

## 一、授權（開放原始碼元件）

| 項目 | 風險 | 處理方式 | 狀態 |
|---|---|---|---|
| Qt 6（LGPL v3） | 閉源軟體須讓使用者能替換 Qt 函式庫 | 以 DLL 動態連結（windeployqt），未修改 Qt 原始碼；關於頁與「授權資訊」列出授權與原始碼網址 | OK |
| Qt 與 MSIX 的 LGPL「可替換」要求 | MSIX 安裝目錄為唯讀，使用者不易替換 DLL | 同時提供可攜版（dist 資料夾）即可滿足；並在授權資訊提供原始碼索取信箱 | OK（建議日後在網站提供可攜版下載） |
| FFmpeg（LGPL v3） | 若誤用 GPL 版（含 x264）會讓整個軟體須開源 | 只附 LGPL 版（BtbN lgpl / `--enable-version3`）；`build.ps1` 會偵測 `--enable-gpl`、`--enable-nonfree` 並拒絕打包；以獨立程式呼叫，不靜態連結 | OK |
| FFmpeg 原始碼提供義務 | 須能提供對應版本原始碼 | 授權資訊列出原始碼網址與索取信箱；隨附 SOURCE.txt / LICENSE.txt | OK |
| FFmpeg 商標 | 不可暗示 FFmpeg 官方背書 | 只在授權說明中提及 | OK |

| 項目 | 風險 | 處理方式 | 狀態 |
|---|---|---|---|
| H.264 編碼 | 自行散布 H.264 軟體編碼器可能涉及專利授權 | 只使用作業系統或顯示卡驅動提供的硬體／系統編碼器（Intel QSV、NVIDIA NVENC、AMD AMF、Windows Media Foundation），授權由硬體與 Windows 廠商負責；已移除 libopenh264（自行編譯版不在 Cisco 授權範圍）；不使用 x264 | OK |
| MPEG-4 Part 2（最後備援） | 主要專利多已到期 | 只有在沒有任何 H.264 編碼器時才使用 | 低風險 |
| GIF | LZW 專利已於 2004 年全球到期 | 無 | OK |
| MP4 / MKV 容器 | 無已知授權費 | 無 | OK |

## 四、程式穩定性（防當機）

| 情境 | 處理方式 |
|---|---|
| 解析度變更、全螢幕遊戲、鎖定畫面、UAC 安全桌面 | DXGI 失效時每 0.5 秒重試，期間持續輸出上一張畫面；連續失敗改用 GDI，並每 5 秒嘗試切回 DXGI |
| 錄影中解析度改變 | 新畫面自動縮放到原輸出大小，ffmpeg 不會收到大小不符的資料 |
| 系統過載 | 落後超過 1 秒時放棄補格，避免越拖越慢 |
| 高更新率螢幕（120/144 Hz） | 依影格率定時取最新畫面，不會每次桌面更新都複製，省 CPU/GPU |
| 長時間 GIF | 先錄成 MKV、停止後兩階段轉 GIF，不會把整段影片放在記憶體；轉檔失敗時保留 MKV |
| ffmpeg 異常結束 | 寫入失敗立即停止，顯示 ffmpeg 錯誤訊息 |
| 磁碟空間不足 | 開始前需 300 MB；錄影中低於 150 MB 自動停止並存檔 |
| Windows 登出／關機 | 收到工作階段結束通知時先停止錄影，讓檔案完整寫入 |
| 結束程式 | 錄影中會先存檔再結束；背景偵測編碼器的執行緒會被取消並等待結束 |
| 重複開啟程式 | 單一執行個體鎖，避免快捷鍵衝突 |

## 五、路徑（不同電腦、不同安裝位置）

| 項目 | 處理方式 |
|---|---|
| 程式安裝位置 | 所有資源（圖示、說明、翻譯）都編進 exe；Qt 外掛與翻譯由 windeployqt 放在 exe 旁，不依賴固定路徑 |
| FFmpeg 位置 | 依序尋找：設定中指定的路徑 → exe 旁 → `ffmpeg\` 子資料夾 → `ffmpeg\bin\` → 系統 PATH。指定的路徑在另一台電腦不存在時會自動往下找 |
| MSIX（Store 版） | 安裝在 `C:\Program Files\WindowsApps\…`，FFmpeg 位於套件內 `ffmpeg\ffmpeg.exe`，以完整信任執行 |
| 中文或含空白的路徑 | 啟動 ffmpeg 使用 Unicode（CreateProcessW）並正確加引號，ffmpeg 在 Windows 以 UTF-8 處理參數 |
| 影片輸出位置 | 預設為使用者的「影片\qScreenRec」（支援 OneDrive 重新導向）。設定的資料夾不存在或無法寫入時（例如另一台電腦沒有 D 槽、隨身碟已拔除），自動改存預設資料夾並通知 |
| 檔名衝突 | 同一秒內多次錄影會自動加上 _2、_3 |
| 設定與暫存 | 設定存在登錄檔（Store 版自動虛擬化）；ffmpeg 記錄檔存在 %TEMP% |
